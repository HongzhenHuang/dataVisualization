# 🌍 Interactive World Map

This project is an **interactive data visualization tool** that displays global indicators (e.g., Life Expectancy, GDP, Population) on a **world map** using Plotly.

## 🚀 Features

* Upload your own CSV data file.
* Choose different indicators to visualize.
* Adjust the year with a slider.
* Auto-play yearly changes to see trends over time.
* Beautiful and responsive UI design.

## 🧩 Tech Stack

* **HTML / CSS / JavaScript**
* **Plotly.js** for interactive maps
* **PapaParse** for CSV parsing

## 📂 How to Use

1. Open `index.html` in your browser.
2. Click **“Choose File”** to upload your CSV data.
3. Select an indicator and adjust the year slider.
4. (Optional) Click **Play** to animate the changes by year.

## 📁 CSV Format Example

Your CSV should include at least these columns:

```
Country,Year,Life expectancy,GDP,Population,...
China,2015,76.1,10500,1376048943
United States of America,2015,79.3,56000,321418821
```
